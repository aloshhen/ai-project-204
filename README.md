# WEBSITE Project

> 🤖 Этот проект был автоматически сгенерирован с помощью AI Constructor Bot

## 📝 Описание

Детальный промпт для создания копии сайта Paper Tiger
Создай современный одностраничный веб-сайт для сервиса управления документами Paper Tiger с следующими характеристиками:
Общий дизайн и стиль

Чистый, профессиональный корпоративный дизайн с акцентом на удобство и читаемость
Цветовая схема: основной цвет - насыщенный синий (#0066CC или похожий), белый фон, акценты оранжевого/кораллового цвета для кнопок призыва к действию
Современная типографика с четкой иерархией заголовков
Много "воздуха" между секциями, не перегруженный дизайн
Адаптивная верстка для всех устройств

Структура сайта (сверху вниз)
1. Шапка (Header)

Фиксированная прозрачная/белая навигация с логотипом слева
Меню: Products, Solutions, Resources, Pricing, Support, About
Кнопка "Sign In" и яркая кнопка "Start Free Trial" справа
При прокрутке - тень под хедером

2. Главный герой-блок (Hero Section)

Крупный заголовок: "Get Organized. Stay Organized. Forever."
Подзаголовок о том, что это система индексации документов
Два поля ввода: Email и кнопка "Start Your Free Trial"
Маленький текст: "No credit card required"
Справа - визуализация продукта (скриншот интерфейса или иллюстрация организованных документов)

3. Логотипы доверия

Секция с текстом "Trusted by thousands of businesses and individuals"
Ряд логотипов известных компаний/организаций (5-7 штук в сером цвете)

4. Блок "Проблема-Решение"

Заголовок: "Stop wasting time searching for documents"
Описание проблемы поиска документов
Три колонки с иконками и преимуществами:

Быстрый поиск (иконка лупы)
Организация (иконка папок)
Доступ отовсюду (иконка облака)



5. Демонстрация функционала

Чередующиеся блоки (зигзагом):
Блок 1 (изображение слева, текст справа):

Заголовок: "Index Everything"
Описание: возможность индексировать физические и цифровые документы
Скриншот интерфейса индексации

Блок 2 (текст слева, изображение справа):

Заголовок: "Find Anything in Seconds"
Описание: мощная система поиска
Скриншот поиска

Блок 3 (изображение слева, текст справа):

Заголовок: "Access from Anywhere"
Описание: облачный доступ с любых устройств
Изображение с разными устройствами



6. Секция "Для кого это"

Заголовок: "Perfect for Everyone"
Карточки для разных аудиторий:

Small Business (иконка + краткое описание)
Home Office (иконка + краткое описание)
Enterprise (иконка + краткое описание)
Non-Profit (иконка + краткое описание)



7. Отзывы

Заголовок: "What Our Customers Say"
2-3 карточки отзывов с:

Цитата клиента
Фото/аватар
Имя, должность, компания
5 звезд рейтинга



8. Тарифы (Pricing)

Заголовок: "Choose Your Plan"
Переключатель Monthly/Annual
3 колонки тарифов:

Basic (простой план)
Professional (выделенный как "Most Popular")
Business (расширенный)


Каждый с: ценой, списком функций, кнопкой "Get Started"

9. FAQ

Заголовок: "Frequently Asked Questions"
5-7 вопросов с раскрывающимися ответами (аккордеон)
Вопросы типа: "How does it work?", "Is my data secure?", "Can I cancel anytime?"

10. Финальный CTA

Яркий фоновый блок (градиент синего)
Заголовок: "Ready to Get Organized?"
Подзаголовок: "Start your free 30-day trial today"
Форма email + кнопка "Start Free Trial"
Текст: "No credit card required • Cancel anytime"

11. Футер (Footer)

Темный фон
4 колонки:

Логотип + краткое описание
Products (ссылки)
Company (ссылки)
Support (ссылки)


Низ: Copyright, Privacy Policy, Terms, Social media иконки

Технические требования

Используй React для интерактивности
Все в одном файле .jsx
Tailwind CSS для стилизации (только core классы)
Плавные анимации при прокрутке (fade-in эффекты)
Иконки из lucide-react
Интерактивные элементы: hover эффекты на кнопках и карточках
Аккордеон для FAQ
Модальные окна не нужны, все на одной странице

Визуальные акценты

Используй современные иллюстрации или градиентные фоны вместо фото где возможно
Скругленные углы у карточек и кнопок
Тени для создания глубины
Яркие кнопки CTA (оранжевый/коралловый)
Профессиональные бизнес-иконки

## 🚀 Технологии

- React (для интерактивности и компонентного подхода)
- Tailwind CSS (для стилизации с использованием core классов)
- lucide-react (для иконок)
- Framer Motion или React Intersection Observer (для плавных анимаций при прокрутке)
- Vite или Create React App (для сборки проекта)
